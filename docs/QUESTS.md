# Daily quest pool (draft for review)

A first pool of 50 quests for the server to pick daily quests from. Go through it, tick **Keep**, change goals or points, and strike what you don't want.

Every quest can be checked with data the client already records:

- **Runs:** Run History, from the DPS logger: dungeon, clear time, bosses, your DPS and rank, deaths.
- **Dungeon stats:** dungeons entered, from `dungeon.stats`.
- **Drops:** collectible UT/ST/top-tier items, with bag color, enchant count and dungeon.
- **Bags:** every loot bag that opens near you, by color.
- **Characters:** fame samples, level, stats maxed, alive or dead.
- **Exalts** and **pets:** exaltation progress, and pet ability levels.
- **Guild hall:** shooting range DPS per loadout.

**Difficulty:**

- **E:** easy, about 15 minutes.
- **M:** medium, about 1 hour.
- **H:** hard, a long session or some luck.

A daily set could be 2 E, 2 M and 1 H.

**Points** are a suggestion for a future guild score.

## Notes for later

- **Guild-wide quests** like #50 need the server to add up members' syncs. The others can be checked by each client and confirmed by the server from the synced documents.
- **Dungeon names** in goals have to match the map names the client records in Run History, like "Lost Halls" and "The Shatters".
- **#14** depends on the dungeon stats, which only count entries, not clears. Cut it if that's too loose.
- **Timing:** "In one day" and "today" should use the server's daily reset, not each player's local midnight.
